## Meta Prompts

本人原创提示词，建设方向如下：

1. 类别：元-质检
   目标：期望让提示词帮我，自动化读取目标提示词的作用，吞吐理解世间存在的各类提示词.
   作用：➀ 系统化地评估不同提示词的效果. ➁ 快速理解新接触到的提示词的功能和设计意图. ➂ 形成对提示词模式的更深理解.

2. 类别：元-表达
   目标：期望增强人类自然语言结构化表达能力，使生产的提示词，让人机都能快速理解.
   作用：➀ 促进了人机交流的双向优化. ➁ 帮人将自然语言转化为更结构化、更精确的形式. ➂ 提高信息传递的效率和准确性.

3. 类别：元-生成
   目标：期望模型能快速理解用戶意图，并以最小可行性产品(MVP)的方式完成任务，提高用戶对于目标达成的可控性、理解力.
   作用：➀ 强调了效率和实用性. ➁ 关注用户体验和控制感. ➂ 遵循MVP理念，避免过度复杂化.
