## 【核心能力】
1. 理解MDC文件格式和Cursor规则系统
2. 识别项目技术栈和架构模式
3. 生成多个协同工作的专项MDC文件
4. 提供清晰的使用指导和最佳实践

### 第四阶段：MDC文件集生成

基于收集的信息，生成以下MDC文件集：

#### 1. **cursor.mdc** (主配置文件)
```mdc
# ==============================================================================
#                 CURSOR.MDC - [项目名称] 主配置
# ==============================================================================
# 生成时间: [timestamp]
# 项目类型: [identified_type]
# ==============================================================================

[general]
# 核心上下文文件
auto-include = 
  # 架构文档
  docs/architecture.md,
  # 项目配置
  [config_files],
  # 类型定义
  [type_definitions]

[docs]
# 项目依赖的官方文档
[framework] = [framework_docs_url]
[libraries] = [library_docs_urls]

[file-rules]
# 全局规则
path = "**/*"
- [global_rules]
```

#### 2. **frontend.mdc** (前端专项规则)
```mdc
# ==============================================================================
#                 前端开发规则
# ==============================================================================

[file-rules]
# 组件规则
path = "[component_path]"
- [component_specific_rules]

# 样式规则
path = "[styles_path]"
- [styling_rules]

# 状态管理
path = "[state_path]"
- [state_management_rules]
```

#### 3. **backend.mdc** (后端专项规则)
```mdc
# ==============================================================================
#                 后端开发规则
# ==============================================================================

[file-rules]
# API路由
path = "[api_path]"
- [api_rules]

# 数据模型
path = "[models_path]"
- [model_rules]

# 服务层
path = "[services_path]"
- [service_rules]
```

#### 4. **testing.mdc** (测试专项规则)
```mdc
# ==============================================================================
#                 测试规则
# ==============================================================================

[file-rules]
# 单元测试
path = "**/*.test.*"
- [unit_test_rules]

# 集成测试
path = "**/integration/**"
- [integration_test_rules]

# E2E测试
path = "**/e2e/**"
- [e2e_test_rules]
```

#### 5. **docs.mdc** (文档规则)
```mdc
# ==============================================================================
#                 文档规则
# ==============================================================================

[file-rules]
# Markdown文档
path = "**/*.md"
- [markdown_rules]

# API文档
path = "**/api-docs/**"
- [api_doc_rules]

# 代码注释
path = "**/*.{js,ts,py,java}"
- [comment_rules]
```
